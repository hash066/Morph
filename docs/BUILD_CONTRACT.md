# Build contract — 2026-10-19

Scope: SO-101 state vial placement only; Newton/MJWarp. No hardware executor.
Lead owns all code, schemas, locks and integration; specialist streams run sequentially.

Acceptance before a recovery claim: pinned stack smoke test, trained or legitimately sourced
checkpoint, repeated feasible failure, controller sensitivity test, one bounded candidate,
real authorized Nebius execution and real Nemotron trace. All remain separate gates.
Do not expand the workbench UI before this gate. Independent orchestration and evidence
components may be built/tested using explicitly labeled fixtures; fixtures cannot become
simulation evidence.

Core regression criteria: frozen schemas reject unknown/executable fields; model sees only
allowlisted development observations; duplicate jobs reserve budget once; concurrent budget
reservations cannot overspend; cancellation and stale leases never fabricate completion;
missing episodes and duplicates cannot inflate success; incomplete comparisons refuse recovery;
held-out outcomes cannot guide selection; export hashes immutable inputs and outcomes.

Budget policy: no provisioning code or automatic purchase. Default cloud/inference allowance
is zero. A bounded, expiring credit authorization and verified account model are prerequisites
for inference. Reserve worst-case cost before a request; uncertain failures consume reservation.
Simulation controller ranges are provisional until measured. Baseline-only smoke runs do not
establish recovery capability. Account credentials stay in process environment only.
